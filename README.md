# Succession_and_Nitrogen_Availability Summary
This study examines how variations in plant diversity, abundance, and species richness over successional time can be explained by environmental factors along ocean dunes in Douglas County, Oregon. This paper was created for BIO 370 Ecology course at the University of Oregon.

# Project Structure:
* **dune_analysis.ipynb**: contains Python codes for plots and statistical tests used in paper
* **dune_data.xlsx**: contains data used for this project
* **dune_paper.pdf**: contains PDF of paper
